# Rail Track Structure

`RailTrackStructure` — spline-backed track with mesh and/or SDF-max part catalog.

Parts (tooltips on fields): rails (classic/modern, head/web/foot curves), sleepers, ballast rubble + noise, sub-ballast, geotextile, spikes/clips, tie plate, fishplate, rail anchor, switch (point/frog/heel/wing/rod/headblocks + BT throw), crossings, junctions, lights/signs.

Resolve travel: `RailTrackStructure.FindBySegmentId(railSegmentId)`.
