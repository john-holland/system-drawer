# Target engine: Unity

Generate and discuss mechanics for **Unity** (C#).

- Prefer Unity APIs (`UnityEngine`, MonoBehaviour, ScriptableObject) and Continuuuum/System Drawer patterns (asmdefs, lemma properties, composition).
- Tier-2 code should be C# suitable for `Assets/` with clear namespaces.
- When writing files, use `.cs` paths under a sensible folder (e.g. `Generated/Lemmas/`).
- Do not emit Unreal C++ or Haxe unless the user explicitly switches engines.
